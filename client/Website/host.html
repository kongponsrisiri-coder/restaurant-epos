Install SiamEPOS Hostติดตั้ง SiamEPOS Host

This makes an Android tablet the main till (the host) — it runs your shop's system, and all the other tablets and tills connect to it. Most shops need only one host. แอปนี้จะทำให้แท็บเล็ต Android เป็น เครื่องหลัก (โฮสต์) ของร้าน เป็นเครื่องที่รันระบบทั้งหมด และเครื่องอื่น ๆ จะเชื่อมต่อเข้ามาที่เครื่องนี้ ร้านส่วนใหญ่ต้องการโฮสต์เพียงเครื่องเดียว

Only one device should be the host. If you just want an extra ordering tablet that connects to an existing till, install the tablet (satellite) app instead — not this one. ควรมีเครื่องโฮสต์เพียงเครื่องเดียว ถ้าคุณต้องการแค่แท็บเล็ตสั่งอาหารเพิ่มที่เชื่อมต่อกับเครื่องหลักที่มีอยู่ ให้ติดตั้ง แอปแท็บเล็ต (satellite) แทน ไม่ใช่แอปนี้
Download SiamEPOS Hostดาวน์โหลด SiamEPOS Host SiamEPOS-Host-v1.76.apk
Open this page on the tablet that will BE the host — not on a computer. The file installs onto the device you download it on. เปิดหน้านี้บนแท็บเล็ตเครื่องที่จะเป็นโฮสต์ ไม่ใช่บนคอมพิวเตอร์ เพราะไฟล์จะติดตั้งลงบนเครื่องที่ดาวน์โหลดเท่านั้น

How to installวิธีติดตั้ง

  1. Tap Download SiamEPOS Host above, then open the downloaded file. กด ดาวน์โหลด SiamEPOS Host ด้านบน แล้วเปิดไฟล์ที่ดาวน์โหลดมา
  2. Android will ask permission to install from your browser. Tap Settings, switch on Allow from this source, then go back. Once per tablet. ระบบจะขออนุญาตติดตั้งจากเบราว์เซอร์ ให้กด การตั้งค่า เปิด อนุญาตจากแหล่งนี้ แล้วย้อนกลับ ทำครั้งเดียวต่อเครื่อง
  3. Tap Install, then open the app and follow the first-time setup below. กด ติดตั้ง จากนั้นเปิดแอปแล้วทำตามการตั้งค่าครั้งแรกด้านล่าง
You may see a security warning because the app is installed directly, not from the Play Store. This is normal — choose to continue or install anyway. The app is signed by SiamEPOS. อาจมีคำเตือนด้านความปลอดภัย เพราะติดตั้งโดยตรง ไม่ได้ผ่าน Play Store ถือเป็นเรื่องปกติ ให้เลือกดำเนินการต่อ แอปนี้มีลายเซ็นรับรองจาก SiamEPOS

First-time setup (like the PC host)การตั้งค่าครั้งแรก (เหมือนเครื่องหลักบน PC)

  1. On first launch, enter your restaurant name, cloud address, restaurant ID and sync key — the same four details as the PC host (we provide these). เมื่อเปิดครั้งแรก ให้กรอก ชื่อร้าน, ที่อยู่คลาวด์, รหัสร้าน และ sync key ซึ่งเป็นสี่ค่าเดียวกับเครื่องหลักบน PC (เราจะให้ข้อมูลนี้)
  2. Allow the Local Network permission if asked — the other tablets reach the host over Wi-Fi. อนุญาต Local Network หากระบบถาม เพราะเครื่องอื่นจะเชื่อมต่อมาที่โฮสต์ผ่าน Wi-Fi
  3. Reserve the host's IP on your router (DHCP reservation). This keeps its address fixed so the other tablets never lose it after a router restart. (No Windows Firewall step is needed on Android.) จองหมายเลข IP ของโฮสต์บนเราเตอร์ (DHCP reservation) เพื่อให้ที่อยู่คงที่ เครื่องอื่นจะได้ไม่หลุดการเชื่อมต่อเมื่อเราเตอร์รีสตาร์ท (บน Android ไม่ต้องตั้งค่า Firewall แบบ Windows)
  4. On each other tablet, open the tablet app and scan the QR shown on this host (Admin → Settings), or type the host's address. บนแท็บเล็ตเครื่องอื่น เปิด แอปแท็บเล็ต แล้วสแกน QR ที่แสดงบนโฮสต์ (Admin → Settings) หรือพิมพ์ที่อยู่ของโฮสต์

Keep the host runningดูแลให้โฮสต์ทำงานตลอด

  • Keep it plugged in and awake — the host is your shop's server; if it sleeps, the other tablets can't order. ให้ เสียบสายชาร์จและเปิดหน้าจอตลอด เพราะโฮสต์คือเซิร์ฟเวอร์ของร้าน ถ้าหลับ เครื่องอื่นจะสั่งอาหารไม่ได้
  • Keep it stationary and on the shop Wi-Fi — don't carry the host around. ตั้งไว้ กับที่และเชื่อม Wi-Fi ของร้าน อย่าถือโฮสต์เดินไปมา
  • Android 7 or newer. รองรับ Android 7 ขึ้นไป
